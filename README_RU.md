# NEON DISTRICT 3D

Стартовый 3D-прототип в Godot 4.3+ в жанре open-world action с ночным неоновым городом.

## В проекте
- Процедурный город, дороги, здания и неоновые элементы.
- Персонаж с видом от третьего и первого лица (V).
- Передвижение, бег, стрельба и рукопашная атака.
- Машины с посадкой/выходом и базовым управлением.
- Гражданские и враждебные NPC.
- Полиция и уровень розыска.
- Простые задания, магазин, гараж, убежище и инвентарь.
- Локальное сохранение прогресса.
- Начальная заготовка сетевого подключения ENet/WebSocket.

## Управление
- WASD — движение / руль
- Мышь — обзор и прицеливание
- ЛКМ — выстрел
- F — удар
- E — сесть в машину / выйти или взаимодействовать
- Shift — бег
- V — переключить камеру
- I — показать инвентарь
- H — использовать аптечку
- F5 / F9 — сохранить / загрузить
- Esc — освободить курсор

## Запуск
1. Установи Godot Engine 4.3 или новее.
2. В Godot Project Manager импортируй файл `project.godot`.
3. Открой проект и нажми F6/F5.

## Экспорт
Нужны Godot Export Templates той же версии, что и редактор.
- Windows: `build_windows.bat`
- Web: `build_web.bat`
- Linux/macOS shell: `build_linux.sh`

GitHub Actions workflow `.github/workflows/build.yml` запускается при push в main/master и вручную через Actions. Он пытается проверить проект и создать Windows/Web артефакты.

Web экспортируй целиком: на HTTPS-хостинг нужно загрузить все файлы из папки `build/web`, а не только HTML.

## Ограничения
Это прототип, а не законченная игра уровня GTA 5. Используются примитивные процедурные модели. Сетевой менеджер пока обеспечивает только базовое подключение: полноценной синхронизации игроков, машин и NPC, серверной логики, лобби и античита нет. Для онлайн-игры потребуется отдельный сервер.

Проект не считается протестированным релизом, пока Godot не выполнит импорт без ошибок, обе сборки не завершатся успешно и билды не будут проверены на целевых устройствах.
